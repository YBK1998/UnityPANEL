# United Control Box — RichAuto A11

CNC router control box: design manual, circuit simulator and parts list.

| Path | What it is |
|---|---|
| `United_Box_A11_Manual_rev0.5.pdf` | Design spec and commissioning manual (rev 0.5) |
| `A11_Box_Parts_List.pdf` | Parts to buy for the wiring rev 0.7 box (generated by `A11_CircuitSim/Verification/make_parts_list.py`) |
| `A11_Wire_List.pdf` | One row per wire with marking, cut length, ends and the checks before wiring; one A4 sheet, double-sided (`make_wire_list.py`) |
| `A11_Build_Steps.pdf` | The same wires in 10 stages that are each tested before the next (earth, supply + 24 V, K1 latch, KM1, ...), with dead and live tests (`make_build_steps.py`) |
| `A11_CircuitSim/` | Unity 6000.6.3f1 project: live schematic, 3D enclosure with routed wiring, multimeter, procedures, build guide — see its README |
| `A11_CircuitSim/Build/A11CircuitSim.exe` | Windows player (run directly) |
| `A11_CircuitSim/Verification/` | Wire schedule, wiring-rule check, wire lengths, self-test report and the verification notes |
